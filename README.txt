CASO PRÁCTICO
Transformando nuestra primera página web
==========================================================

OBJETIVO
---------

En este ejercicio continuaremos trabajando sobre la página
web desarrollada en el Tema 1.2.

El objetivo es transformar una página HTML sencilla en una
página web moderna y atractiva utilizando únicamente CSS.

IMPORTANTE

No está permitido modificar el archivo index.html.
Todo el trabajo deberá realizarse desde la hoja de estilos
styles.css.

OBJETIVOS DEL EJERCICIO
-----------------------

□ Aplicar una tipografía común a toda la página.

□ Dar estilo a la cabecera y al menú de navegación.

□ Organizar el contenido mediante Flexbox.

□ Diseñar las tarjetas de contenido.

□ Mejorar el aspecto del formulario.

□ Crear botones con efecto hover.

□ Diseñar un pie de página coherente.

□ Adaptar la página a dispositivos móviles.


PISTAS
------

Se recomienda desarrollar la hoja de estilos en el siguiente
orden:

1. Variables CSS.

2. Estilos generales.

3. Cabecera.

4. Menú de navegación.

5. Contenido principal.

6. Tarjetas.

7. Panel lateral.

8. Formulario.

9. Pie de página.

10. Diseño responsive.


RESTRICCIONES
-------------

✓ Utilizar únicamente CSS.

✓ No modificar index.html.

✓ No añadir librerías CSS externas.

✓ Utilizar las variables CSS definidas en :root.

✓ Mantener un código limpio y correctamente indentado.


SE VALORARÁ
-----------

• Organización de la hoja de estilos.

• Correcto uso de los selectores CSS.

• Aplicación del modelo de caja.

• Utilización adecuada de Flexbox.

• Uso coherente de colores y tipografía.

• Aspecto visual de la página.

• Adaptación a dispositivos móviles.

• Legibilidad y mantenimiento del código.


RESULTADO ESPERADO
------------------

Al finalizar el ejercicio la página deberá presentar un
aspecto similar al mostrado en el enunciado del caso práctico,
manteniendo exactamente la misma estructura HTML desarrollada
en el Tema 1.2.

El objetivo no es copiar el diseño píxel a píxel, sino aplicar
correctamente los conceptos estudiados durante el tema para
obtener una página web limpia, coherente y visualmente atractiva.
